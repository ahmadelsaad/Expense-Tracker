# Personal Expense Analytics Dashboard

An end-to-end personal expense tracking and analytics project built with **Python, SQLite, Power BI, and DAX**.

The project combines a Python-based expense management application with a SQLite database and an interactive Power BI dashboard to track transactions, analyze spending patterns, and visualize monthly and category-level trends.

## Project Overview

I made this project to understand and work with the full data workflow.

In this project, users can add, view, delete, search, and filter expenses through a Python application. Transactions are stored in a SQLite database, which serves as the data source for an interactive Power BI dashboard.

The dashboard analyzes expense activity from January to August using a synthetic dataset designed to simulate realistic recurring bills and everyday spending.

## Tech Stack

- **Python** — application logic and expense management
- **SQLite** — local relational database for transaction storage
- **SQL** — querying and managing expense records
- **Power BI** — data modeling and dashboard development
- **DAX** — calculated columns and analytical measures
- **Matplotlib** — visual summaries within the Python application
