Expense-Tracker
A Python expense tracking app with SQL database and data visualization

A command-line personal finance application built in Python that lets users log, manage, and analyze spending habits through an interactive menu and data visualizations.

Features
- Add, view, and delete expenses with name, amount, category, and date
- SQLite database for persistent data storage
- Visual summary dashboard with bar chart, pie chart, and spending over time line graph
- Search and filter expenses by category or date
- Input validation to prevent crashes from bad input

Technologies
Python, SQLite3, SQL, Matplotlib
